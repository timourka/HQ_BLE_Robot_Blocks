# HQ_BLE Robot Blocks v1.1

Визуальный блочный редактор для робота `HQ_BLE`, совместимого с приложением STEM.

## Возможности

- подключение к `HQ_BLE` через обычный Bluetooth LE адаптер Windows;
- автоматическая STEM-проверка после подключения;
- блочная программа с перетаскиванием и изменением порядка;
- движение: вперёд / назад / налево / направо / стоп;
- длительность движений;
- паузы;
- циклы `ПОВТОРИТЬ ... КОНЕЦ ПОВТОРА`, в том числе вложенные;
- редактор LED-матрицы 5×5;
- программная бегущая строка (русский/латинский 5×5 шрифт, скорость и длительность);
- мелодии 0–20;
- произвольная HEX-команда;
- аварийный STOP;
- сохранение/открытие программ в JSON;
- BLE-журнал TX/RX.

## Установка на Windows

Рекомендуется Python 3.11+.

Проверьте Tkinter:

```powershell
python -m tkinter
```

Затем:

```powershell
python -m pip install -r requirements.txt
python robot_blocks.py
```

Встроенный Bluetooth Windows подходит — отдельный Nordic dongle не нужен.

## BLE протокол

- Device name: `HQ_BLE`
- Service: `0000AE00-0000-1000-8000-00805F9B34FB`
- AE01: `Write Without Response`
- AE02: `Notify`

Команды:

| Действие | HEX |
|---|---|
| Stop | `00` |
| Вперёд | `01 08` |
| Назад | `01 04` |
| Налево | `01 02` |
| Направо | `01 01` |
| Мелодия N (0…20) | `02 NN` |
| Матрица 5×5 | `03 R1 R2 R3 R4 R5` |

Для движения программа повторяет пакет примерно каждые 200 мс и затем отправляет `00`.

## Матрица 5×5

Каждая строка — один байт, используются младшие 5 бит.

Пример:

```text
01010
11111
11111
01110
00100
```

Отправляется как:

```text
03 0A 1F 1F 0E 04
```

## Если HQ_BLE не находится

1. Убедитесь, что робот включён.
2. Закройте STEM и Bluetooth LE Explorer — BLE-устройство может быть занято другим приложением.
3. Убедитесь, что Bluetooth включён в Windows.
4. Попробуйте выключить и включить робота.
5. Запустите программу обычным пользователем; отдельный драйвер Bleak для Windows не требуется.

## Важно

Во время первых тестов поставьте робота так, чтобы колёса не могли неожиданно уехать со стола. В программе есть аварийный STOP и защитная отправка STOP после каждого блока движения.


## Бегущая строка

В оригинальном APK отдельной BLE-команды «бегущая строка» не найдено.
Блок реализован программно: текст преобразуется в 5×5 пиксельный шрифт, после
чего программа последовательно отправляет обычные кадры матрицы:

```text
03 R1 R2 R3 R4 R5
```

Параметры блока:

- текст;
- интервал между кадрами (по умолчанию 0.15 с);
- общая длительность; `0` означает один полный проход.

Поддерживаются латинские и русские буквы, цифры и базовая пунктуация.

## Что найдено по громкости

В декомпилированном DEX приложения STEM отдельной команды регулировки
громкости робота не найдено. Класс `com.weifeng.octopusrobot.utils.Agmt`,
в котором формируются BLE-команды, содержит генераторы `playMusicHex`,
`showLightHex`, `showLightHex1`, `wayHex` и `reset`; volume-команды там нет.
Поэтому неподтверждённую команду громкости в программу не добавлял.

`playMusicHex(int)` формирует строку `"02" + TypeUtil.numToHex8(n)`, поэтому
значение мелодии `0` поддержано как пакет `02 00`.
